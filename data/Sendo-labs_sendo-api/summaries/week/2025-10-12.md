# Sendo-labs/sendo-api Weekly Report (Oct 12 - 18, 2025)

## 🚀 Highlights
This week marked the inception of the `sendo-api` project. Development kicked off with a significant foundational commit that established the entire initial architecture of the repository. This initial setup included core controllers, services, and configuration files. Crucially, it also introduced a comprehensive suite of utility functions for decoding on-chain transactions from various protocols, laying the essential groundwork for the platform's core mission of analyzing user transaction history.

## 🛠️ Key Developments
All development this week was focused on establishing the project's initial structure and core functionalities in a single, comprehensive effort.

### Project Initialization and Foundational Services
The repository was brought to life with its first major commit, which laid out the complete foundational structure for the Sendo API. This work, captured in PR [#1](https://github.com/Sendo-labs/sendo-api/pull/1), included:
-   **Core Architecture:** Initial setup of controllers for NFTs, tokens, and trades, along with corresponding services and configuration files.
-   **Transaction Decoding Utilities:** A key feature of the initial commit was the implementation of decoders for a wide range of on-chain transaction types. Support was added for protocols including Jupiter, Meteora, Orca, Pumpfun, Pumpswap, Raydium, and Whirlpool, enabling the API to begin processing on-chain data.
