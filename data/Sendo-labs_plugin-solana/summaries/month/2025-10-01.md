## 🛠️ Key Developments
This month's work centered entirely on improving the project's continuous integration and deployment pipeline.

- **Streamlined Release and Deployment Workflows**
  Significant refactoring was undertaken to enhance how the plugin is published to NPM and how project releases are managed. The previous `npm-deploy` workflow was deprecated in favor of two new, dedicated GitHub Actions: `publish-npm` and `release`. To support this new automation, configuration files for release versioning (`.release-please-manifest.json`) and changelog generation (`release-please-config.json`) were introduced. This effort, captured in PR [#1](https://github.com/Sendo-labs/plugin-solana/pull/1), automates key parts of the release cycle.
