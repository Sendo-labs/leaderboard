### Automated Release and Publishing Workflow
*   Introduced comprehensive CI/CD workflows for automated plugin publishing to NPM.
*   Configured `release-please-manifest.json` and `release-please-config.json` to manage release versions and changelogs, streamlining the release process. ([#8](https://github.com/Sendo-labs/plugin-sendo-analyser/pull/8))

### Asynchronous Wallet Analysis System
*   Implemented an asynchronous job system for wallet analysis, featuring background workers and job status tracking (pending, processing, completed/failed).
*   Integrated real-time progress updates, incremental analysis, and dynamic rate limiting for API calls.
*   Developed extensive caching mechanisms for jobs, prices, and transactions to optimize performance and reduce redundant requests. ([#11](https://github.com/Sendo-labs/plugin-sendo-analyser/pull/11))
