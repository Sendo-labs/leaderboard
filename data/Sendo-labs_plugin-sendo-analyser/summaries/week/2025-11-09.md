# Sendo-labs/plugin-sendo-analyser Weekly Report (Nov 9 - 15, 2025)

## 🚀 Highlights
This period saw significant progress in enhancing the plugin's data analysis capabilities and backend performance. Key achievements include the integration of historical data via the BirdEye API and batch metadata fetching with Helius, which provides more comprehensive on-chain analysis. A new Queue Manager was implemented to handle concurrent job processing, boosting system efficiency and scalability. Additionally, a new leaderboard API with badges and rank titles was introduced, and a series of releases were managed, including a notable version reset to align with a new versioning strategy.

## 🛠️ Key Developments
Work focused on expanding data sources, improving system throughput, and adding new user-facing features.

- **Enhanced Data Retrieval and Processing**
  To improve the depth and accuracy of on-chain analysis, the BirdEye API integration was enhanced to support historical price timeframe data. Helius was also integrated for efficient batch metadata fetching, improving the analysis worker's capabilities ([#15](https://github.com/Sendo-labs/plugin-sendo-analyser/pull/15)). In a parallel effort to boost performance, a new Queue Manager was implemented to handle concurrent job processing, allowing tasks like price fetching to run simultaneously for greater efficiency ([#17](https://github.com/Sendo-labs/plugin-sendo-analyser/pull/17)).

- **New Leaderboard Feature**
  A new leaderboard API was added to the plugin, complete with functionality for badges and rank titles. This feature introduces a competitive overview to the platform's analytical toolset ([#20](https://github.com/Sendo-labs/plugin-sendo-analyser/pull/20)).

- **Release Management and Versioning**
  A significant amount of effort was dedicated to release management. Releases for versions 1.0.0, 1.1.0, and 1.2.0 were performed ([#16](https://github.com/Sendo-labs/plugin-sendo-analyser/pull/16), [#18](https://github.com/Sendo-labs/plugin-sendo-analyser/pull/18), [#21](https://github.com/Sendo-labs/plugin-sendo-analyser/pull/21)). The project version was also bumped to 1.8.0 ([#19](https://github.com/Sendo-labs/plugin-sendo-analyser/pull/19)). Notably, version 2.0.0 was released, which included a breaking change to reset the version number as part of a new versioning alignment strategy ([#22](https://github.com/Sendo-labs/plugin-sendo-analyser/pull/22)).
